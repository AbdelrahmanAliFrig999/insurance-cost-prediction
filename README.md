# Insurance Premium Prediction

## Project Overview
This project uses machine learning to predict annual insurance premiums based on customer demographics, health-related attributes, and medical cost indicators.

## Objectives
- Explore and analyze insurance data.
- Clean and preprocess data for machine learning.
- Select relevant features for prediction.
- Train and compare multiple regression models.
- Evaluate model performance using standard regression metrics.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

## Model Evaluation
The models were evaluated using:
- RMSE (Root Mean Squared Error)
- MAE (Mean Absolute Error)
- R² Score

Linear Regression achieved the best performance among the evaluated models, with an R² score of approximately 0.9325.

## Project File
The Jupyter Notebook contains the data analysis, preprocessing, model training, and evaluation workflow.
